# Contributing

How to add a new skill or change an existing one.

## Repository structure

```
ai-skills/
├── .claude-plugin/
│   └── marketplace.json        # skill catalog (generated by build.py)
├── plugins/
│   └── <skill-name>/
│       ├── .claude-plugin/
│       │   └── plugin.json     # name, version, description
│       └── skills/
│           └── <skill-name>/
│               └── SKILL.md    # the skill itself (plus extra files if needed)
├── dist/                       # zip archives for uploading to Claude (generated by build.py)
├── template/                   # template for a new skill
└── scripts/
    ├── new_skill.py            # create a skill from the template
    └── build.py                # validate skills, build zips, update marketplace.json and README
```

## Adding a new skill

1. Create the skill from the template:
   ```
   python3 scripts/new_skill.py sales-coach "Helps prepare sales proposals and handle customer objections."
   ```
2. Write the instructions in `plugins/sales-coach/skills/sales-coach/SKILL.md`. You can add supporting files next to it: references, examples, templates.
3. Build the repository:
   ```
   python3 scripts/build.py
   ```
   The script validates names and descriptions, creates `dist/sales-coach.zip`, adds the skill to `marketplace.json` and to the Skills table in `README.md`.
4. If the skill is based on a book or another source, add it to the Sources section of `README.md`.
5. Commit and push.

## Changing an existing skill

Bump `version` in its `plugin.json` (otherwise Claude Code users won't get the update) and run `build.py` again.

## Two descriptions

- `description` in **SKILL.md** frontmatter is for Claude: it decides from it whether to load the skill. Write it as "what it does + when to use it", include words users actually say, and add other languages if the skill is multilingual. Up to 1024 characters.
- `description` in **plugin.json** is for people: it is shown in the README table and in the `/plugin` catalog. Keep it short and in English.

## SKILL.md rules

- The file must start with a frontmatter block containing `name` and `description`.
- `name`: lowercase letters, digits and hyphens, up to 64 characters. Must match the folder name.
- `description`: no angle brackets.
- To support users in different languages, write instructions in English and add a "reply in the user's language" rule.
- Keep SKILL.md focused. Move long reference material into separate files next to it and tell Claude when to read them.
